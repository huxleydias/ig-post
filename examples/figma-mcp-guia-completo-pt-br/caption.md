O Figma MCP envia contexto de design para o agente. Quem escreve o código é o agente.

Depois de iterar no Figma, o agente lê o design com as suas alterações, atualiza o repositório e abre o pull request. O julgamento de produto continua sendo seu.

No guia tem a instalação no Claude Code, Cursor, Codex e VS Code, os quatro erros de configuração e o fluxo do canvas até o pull request.
